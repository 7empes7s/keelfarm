# Video

Clips, edits and voice-overs. Video needs a video model and a voice: add both providers first.

## Recommended setup

| Job | Coding agent | Why |
| --- | --- | --- |
| Build | Claude Code · Sonnet | Writes scripts and drives the video tools. |
| QA | Claude Code · Sonnet | Drives the Test lab browser and reads screenshots well. |
| Small fixes | Claude Code · Sonnet | Small fixes need speed more than depth. |
| Docs | Claude Code · Haiku | Cheap and quick for docs and copy. |

- **Team:** 2 agents to start.
- **Preview:** not needed.
- **Test lab:** not needed; QA runs commands.

- **Providers:** a video and a audio key in Settings → Providers.

## QA brief

The floor's setup card adds these when they are missing:

- The clip plays, with the length and format the brief asks for

## Getting it ready

1. Add the video and audio providers in Settings → Providers and press Test.
2. Sign in the coding agents above in Settings → Providers & accounts.
3. Tap the recommended button on each card in the floor's Setup section (Floors & repos).
