# Third-party sounds

Every recorded sound the office ships, with where it came from and its licence. Only CC0 / public domain:
`client/src/world/toys/dogSound.test.ts` fails if a file in `client/public/sounds/` has no row here.

Each clip is a cut of under 0.6 s from the original (mono, peak-normalized to -1 dBFS, a short fade in and out),
as `.ogg` (Vorbis) with an `.mp3` of the same cut for browsers that don't play Ogg.
